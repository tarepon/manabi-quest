# ⚔️ まなびクエスト 中1

中学1年生の5教科（数学・英語・国語・理科・社会）を、記憶研究にもとづく方法で学べる無料のゲーム型学習アプリです。ブラウザで `index.html` を開くだけで動きます。インストール・登録は不要です。

## 特徴

### 📚 学習コンテンツ・学習エンジン

- **全245問・27単元収録**（中1の標準的な学習範囲）。クイズ形式に加え、一部は答えを直接入力する入力式問題
- **間隔反復**: 正解するたびに復習間隔を 1→3→7→14→30日 と自動で延長
- **検索練習（テスト効果）**: すべてクイズ形式、全問に解説つき
- **インターリービング**: 5教科を混ぜて出題
- **カリキュラム連動**: 学校の授業進度（前期後期制の目安）に合わせ、習った単元から出題。未習単元は「特訓」から先取り可能
- **修行の部屋**: 「特訓」タブ内の基礎ドリルコーナー。二桁の足し算・引き算、かけ算九九、漢字の読みを入力式でテンポよく反復し、考えなくても答えが浮かぶ「自動化」をめざす

### 📈 学習の成果（XP・レベル・バッジ）

クイズに正解するだけでたまる、いちばん基本のごほうび。

- **ゲーミフィケーション**: XP・レベル・連続日数・36種のバッジ（うち複数種は「ゲキムズ」の激レア実績）

### ⚔️ まなびバトル（モンスター対戦）

なかまを集めて育てるポケモン風の対戦という形をとっていますが、中身はすべて検索練習（クイズ）です。

- **まなびバトル**: 勉強のじゃまをする100体のモンスターと、手持ちモンスターで対戦。正解すると2つの「わざ」から選んでこうげき、まちがえると出撃中のモンスターが反撃を受ける。5教科を五角形のタイプ相性にした「バトル相性」があり、通常モンスターは倒すと**なかまにできる**（最大3体・個体値はゲットのたびにランダム、経験値でレベルアップ）。なかまにすると前向きな姿へ進化（例：ワスレムシ→オボエムシ）。手持ちが瀕死になると次のモンスターに交代しながら戦います。バトル中の解答も復習スケジュールに記録されます（対戦相手はアプリ内のモンスターで、通信対戦はありません）
- **ゲキムズ隠しボス**: 通常の100体をすべて倒すと、弱点なし・桁ちがいのHP＆こうげき力を持つ「裏ボス」3体連戦が出現。真の完全制覇に挑戦できます

### 🎮 まなびゲーセン（ポイント・ガチャ・景品コレクション）

問題に正解して🎫チケットをため、ガチャで景品を集める、勉強の内容とは直接関係のない純粋な「お楽しみ」要素。**景品を持っていること自体はモンスターの強さに影響しません**。

- **チケット**: クエスト・特訓・バトルで問題に正解するたびに獲得。パーフェクトクリアや勝利にはボーナスあり
- **ガチャガチャ**: チケットを消費して回し、コモン〜ウルトラレアの4段階レアリティで20種類の景品（ヨーヨー・王冠・ドラゴンフィギュアなど）を集められる。アメリカのゲームセンターのチケット交換所と同じ「ためて、交換する」楽しさが、次のクエストに向かう動機になる。同じ景品が出た（かぶった）ときはチケットには戻らず、同じレアリティのモンスター強化素材に変わる——コレクションの緊張感を保ちつつ、かぶりも無駄にしない

### 📦 アイテム収集・モンスター強化

バトルの勝利、またはガチャで景品がかぶったときにモンスター素材が手に入る。集めた素材は**モンスターを強くするためだけ**に使う。

- **ドロップアイテム**: バトルに勝つとランダムでモンスター素材（ウロコ・キバ・角など8種、コモン〜ウルトラレア）を1個ひろい、「手持ち」タブのアイテムボックスにたまっていく
- **合成強化**: 手持ちモンスターに素材を使って合成すると、HP・こうげき・剛性（防御）を永続的にきょうかできる。剛性が高いほどバトルで受けるダメージが減る
- **限界突破（覚醒）**: 素材の中でも超レアな「モンスターのたましい」を1個ささげると、モンスターのレベル上限が広がり（たまっていた経験値ぶんいっきにレベルアップ）、個体値（HP・こうげき）も通常の0〜15の枠を超えて永久に伸びる

学習方法の科学的根拠は、アプリ内の「🧠 しくみ」タブに出典つきで掲載しています。

## プライバシー

- 個人情報（名前・メールアドレス等）は一切収集しません
- 学習記録は端末のブラウザ内（localStorage)にのみ保存され、外部に送信されません
- 広告・アクセス解析・Cookieは使用していません
- 外部への通信はContent Security Policyでブラウザレベルでも遮断しています

## 免責事項

本アプリは個人学習を支援する目的で作成されたものです。内容の正確性には配慮していますが、誤りが含まれる可能性があります。学校の授業・教科書の内容を必ず優先してください。単元の学習時期は一般的な目安であり、学校や教科書により前後します。

## 使い方

1. `index.html` をブラウザで開く（またはGitHub Pagesの公開URLへアクセス）
2. 「今日のクエストに出発」で1日10問のミックス出題
3. まちがえた問題は同じクエスト内で正解するまで再出題
4. 毎日続けると復習が自動でスケジュールされます
