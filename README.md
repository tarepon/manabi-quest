# ⚔️ まなびクエスト 中1

中学1年生の5教科（数学・英語・国語・理科・社会）を、記憶研究にもとづく方法で学べる無料のゲーム型学習アプリです。ブラウザで `index.html` を開くだけで動きます。インストール・登録は不要です。

## 特徴

- **全245問・27単元収録**（中1の標準的な学習範囲）。クイズ形式に加え、一部は答えを直接入力する入力式問題
- **間隔反復**: 正解するたびに復習間隔を 1→3→7→14→30日 と自動で延長
- **検索練習（テスト効果）**: すべてクイズ形式、全問に解説つき
- **インターリービング**: 5教科を混ぜて出題
- **カリキュラム連動**: 学校の授業進度（前期後期制の目安）に合わせ、習った単元から出題。未習単元は「特訓」から先取り可能
- **修行の部屋**: 「特訓」タブ内の基礎ドリルコーナー。二桁の足し算・引き算、かけ算九九、漢字の読みを入力式でテンポよく反復し、考えなくても答えが浮かぶ「自動化」をめざす
- **ゲーミフィケーション**: XP・レベル・連続日数・28種のバッジ（うち5種は「ゲキムズ」の激レア実績）
- **まなびバトル**: 勉強のじゃまをする100体のモンスターとのポケモン風対戦モード。正解で攻撃、まちがえると反撃、連続正解でコンボ、モンスターの弱点教科で2倍ダメージ。バトル中の解答も復習スケジュールに記録されます（対戦相手はアプリ内のモンスターで、通信対戦はありません）
- **ゲキムズ隠しボス**: 通常の100体をすべて倒すと、弱点なし・桁ちがいのHP＆こうげき力を持つ「裏ボス」3体連戦が出現。真の完全制覇に挑戦できます

学習方法の科学的根拠は、アプリ内の「🧠 しくみ」タブに出典つきで掲載しています。

## プライバシー

- 個人情報（名前・メールアドレス等）は一切収集しません
- 学習記録は端末のブラウザ内（localStorage)にのみ保存され、外部に送信されません
- 広告・アクセス解析・Cookieは使用していません
- 外部への通信はContent Security Policyでブラウザレベルでも遮断しています

## 免責事項

本アプリは個人学習を支援する目的で作成されたものです。内容の正確性には配慮していますが、誤りが含まれる可能性があります。学校の授業・教科書の内容を必ず優先してください。単元の学習時期は一般的な目安であり、学校や教科書により前後します。

## 使い方

1. `index.html` をブラウザで開く（またはGitHub Pagesの公開URLへアクセス）
2. 「今日のクエストに出発」で1日10問のミックス出題
3. まちがえた問題は同じクエスト内で正解するまで再出題
4. 毎日続けると復習が自動でスケジュールされます
