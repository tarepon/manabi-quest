# ⚔️ まなびクエスト

記憶研究にもとづく方法で学べる無料のゲーム型学習アプリです。ブラウザでHTMLファイルを開くだけで動きます。インストール・登録は不要です。学年ごとに2つのアプリがあります。

| アプリ | ファイル | 対象 | 教科 |
|---|---|---|---|
| まなびクエスト 中1 | `index.html` | 中学1年生 | 数学・英語・国語・理科・社会（全5教科） |
| まなびクエスト 小3 | `elementary3.html` | 小学3年生 | 算数・国語・理科・社会（全4教科） |

小3版は中1版と同じ学習エンジン・バトル・バッジのしくみを使いつつ、出題内容を小学3年の標準的な学習範囲に合わせ、1回のクエストの問題数を少なめ（8問）にするなど、小学生の学習容量に合わせて調整しています。

## 特徴（共通）

- **間隔反復**: 正解するたびに復習間隔を 1→3→7→14→30日 と自動で延長
- **検索練習（テスト効果）**: すべてクイズ形式、全問に解説つき
- **インターリービング**: 教科を混ぜて出題
- **カリキュラム連動**: 学校の授業進度の目安に合わせ、習った単元から出題。未習単元は「特訓」から先取り可能
- **ゲーミフィケーション**: XP・レベル・連続日数・バッジ
- **まなびバトル**: 勉強のじゃまをするモンスターとのポケモン風対戦モード。正解で攻撃、まちがえると反撃、連続正解でコンボ、モンスターの弱点教科で2倍ダメージ。バトル中の解答も復習スケジュールに記録されます（対戦相手はアプリ内のモンスターで、通信対戦はありません）
- **全156問・26単元収録**（中1版）／**全133問・26単元収録**（小3版）

学習方法の科学的根拠は、各アプリ内の「🧠 しくみ」タブに出典つきで掲載しています。

## プライバシー

- 個人情報（名前・メールアドレス等）は一切収集しません
- 学習記録は端末のブラウザ内（localStorage)にのみ保存され、外部に送信されません
- 広告・アクセス解析・Cookieは使用していません
- 外部への通信はContent Security Policyでブラウザレベルでも遮断しています

## 免責事項

本アプリは個人学習を支援する目的で作成されたものです。内容の正確性には配慮していますが、誤りが含まれる可能性があります。学校の授業・教科書の内容を必ず優先してください。単元の学習時期は一般的な目安であり、学校や教科書により前後します。

## 使い方

1. `index.html`（中1）または `elementary3.html`（小3）をブラウザで開く（またはGitHub Pagesの公開URLへアクセス）
2. 「今日のクエストに出発」でミックス出題（中1は10問、小3は8問）
3. まちがえた問題は同じクエスト内で正解するまで再出題
4. 毎日続けると復習が自動でスケジュールされます

2つのアプリの学習記録は別々に保存され、混ざりません。それぞれのアプリ内「🧠 しくみ」タブの下部から、もう一方のアプリへのリンクがあります。
